# Multi-Brand Marketing Campaign Performance Analysis and Prediction

## Project Overview

This project focuses on analyzing marketing campaign performance across multiple brands, including Nykaa, Purplle, and Tira. It uses Python, data analysis, and machine learning to transform raw campaign data into useful business insights and predictive outputs.

The project covers two prediction tasks:
- **Regression:** Predict campaign Revenue.
- **Classification:** Predict campaign Profit/Loss (campaign success).

An interactive Streamlit application is used to accept campaign details and display prediction results.

## Problem Statement

Marketing teams across multiple brands generate large volumes of campaign data, including impressions, clicks, conversion rates, acquisition costs, revenue, and return on investment (ROI). This information may be stored in raw CSV files, making it difficult to analyze and extract meaningful insights.

The data may also contain missing values, duplicate records, inconsistent ROI calculations, and multiple marketing channels in a single column. These issues make preprocessing more complex and can affect the reliability of analysis.

This project aims to clean, preprocess, explore, and transform the data, engineer useful features, build regression and classification models, evaluate their performance, and deploy the models through a Streamlit application.

## Project Objectives

1. Collect and load campaign data from CSV files into Pandas DataFrames.
2. Understand the dataset structure, columns, and data types.
3. Handle missing values and duplicate records.
4. Convert data types and standardize the dataset.
5. Validate and correct ROI values where required.
6. Apply multi-label encoding to the `Channel_Used` feature.
7. Create a Profit/Loss flag based on ROI.
8. Perform exploratory data analysis (EDA).
9. Analyze campaign performance by brand, campaign type, and marketing channel.
10. Build regression models to predict Revenue.
11. Build classification models to predict Profit/Loss.
12. Evaluate and compare model performance.
13. Develop a Streamlit application for interactive predictions.
14. Generate insights and data-driven marketing recommendations.

## Project Workflow

### 1. Data Collection

- Import the campaign dataset in CSV format.
- Load the data into Python using Pandas.
- Inspect the dataset structure, columns, and data types.

### 2. Data Cleaning and Preprocessing

- Identify and handle missing values.
- Remove duplicate records.
- Convert columns to appropriate data types.
- Clean and standardize the dataset.
- Validate and correct ROI values where required.
- Prepare categorical and numerical features for analysis and modeling.

### 3. Feature Engineering

- Apply multi-label encoding to `Channel_Used`, since a campaign may use multiple marketing channels.
- Create a Profit/Loss flag based on ROI, as specified in the problem statement.
- Select relevant features for the prediction tasks.
- Apply feature transformations where needed.

### 4. Exploratory Data Analysis (EDA)

- Analyze campaign performance across brands.
- Identify top-performing and low-performing campaigns.
- Explore relationships between acquisition cost, clicks, revenue, and ROI.
- Analyze marketing-channel effectiveness.
- Generate visualizations to communicate patterns and trends.

### 5. Model Building

Split the dataset into training and testing sets so that model performance can be evaluated on unseen data.

**Regression task**
- Target variable: `Revenue`
- Build regression models to predict revenue from campaign features.

**Classification task**
- Target variable: `Profit_Flag` (the engineered Profit/Loss indicator).
- Build classification models to predict whether a campaign results in profit or loss.
- Exclude `ROI` from the classification input features to avoid data leakage, as required by the problem statement.

**Algorithms named in the problem statement**
- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest

Perform feature selection and parameter tuning where appropriate, and validate the models using the test data.

### 6. Model Evaluation

**Regression metrics**
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

**Classification metrics**
- Accuracy
- Precision
- Recall
- F1-score

**Targets specified in the problem statement**
- Regression: R² >= 0.95
- Classification: Accuracy >= 0.95

These are project evaluation targets, not claims of achieved results. Record the actual test-set metrics after model evaluation.

### 7. Insights and Reporting

- Generate insights into campaign performance.
- Identify factors associated with campaign profitability.
- Provide data-driven recommendations for marketing strategies.
- Support business decision-making using model predictions.

### 8. Streamlit Application

Build an interactive application using Streamlit that allows users to:

1. Enter campaign details, such as impressions, clicks, spend, and channels.
2. Apply the same preprocessing and feature-engineering steps used during model training.
